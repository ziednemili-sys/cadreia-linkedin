# cadreia-linkedin

Visuels des posts de la page LinkedIn Cadreia, générés automatiquement chaque semaine.

- `gabarits/` : feuille de style, pied de page et exemples de mise en page (1080 x 1350).
- `posts/AAAA-MM-JJ.html` : source de chaque visuel.
- `images/AAAA-MM-JJ.png` : visuel publié, lu par Make à l'adresse
  `https://raw.githubusercontent.com/ziednemili-sys/cadreia-linkedin/main/images/AAAA-MM-JJ.png`.
- `rendre.py` : rendu HTML vers PNG avec contrôle de débordement.
